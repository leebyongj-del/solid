# 입체 탐험대

## 웹앱 실행하기

**[입체 탐험대 웹앱 열기](https://solid-discovery-class.leebyongj598693.chatgpt.site/)**

위 링크에서 교사 또는 학생을 선택해 수업에 참여하세요. 학생들에게도 이 웹앱 주소를 공유하면 됩니다.

이 GitHub 저장소는 웹앱의 소스 코드와 설명서를 보관하는 곳입니다. 수업용 화면은 위의 웹앱 링크에서 열립니다.

중학교 1학년 45분 공개수업용 사진·입체도형 탐구 교실입니다.

## 역할과 접속 주소

- `/`: 교사/학생을 선택하는 첫 화면입니다.
- `/teacher`: 교사용 6자리 비밀번호를 입력한 뒤 교사 게시판에 접속합니다. 별도의 ChatGPT 로그인은 필요하지 않습니다.
- `/student`: 수업 코드와 모둠 이름으로 참여하는 학생 전용 화면입니다.

비밀번호는 서버 런타임 비밀값 `TEACHER_PIN_HASH`에 SHA-256 해시로 보관합니다. `TEACHER_SESSION_SECRET`으로 서명한 8시간짜리 교사 세션을 HttpOnly/Secure/SameSite=Strict 쿠키에 설정합니다. 화면 및 수업 관리 API 모두 서명을 검증합니다. 클라이언트 저장값, 이전 교사 토큰, ChatGPT 사용자 ID 헤더만으로는 교사 권한을 얻을 수 없습니다. 교사 화면의 로그아웃은 이 쿠키를 제거하고 첫 화면으로 돌아갑니다. 10분 구간에 접속 위치별 비밀번호 오류가 8번이면 해당 구간의 추가 시도를 차단합니다.

## 교사 화면

새 수업을 열고 수업 코드와 학생용 참여 링크를 안내합니다. 수업을 선택하면 사진을 3초마다 자동으로 불러오며 사진 확대, 학생의 첫 생각과 최종 설명 확인, 단계 변경, 마감/재개, 타이머 및 CSV 내보내기를 지원합니다. 기존 수업도 목록에서 선택할 수 있습니다.

## 학생용 태블릿 흐름

수업 코드·모둠 이름으로 참여한 뒤 한 화면씩 진행합니다.

1. 사진 모으기: 카메라로 차례로 찍거나 앨범에서 여러 사진을 골라 4장을 모읍니다. 사진은 즉시 기기에 저장되고 연결되면 교사 게시판에 전송됩니다.
2. 하나씩 탐구: 사진별로 내 생각 → 도형 비교 → 성질 탐구 → 기록하기를 진행합니다. AI 후보는 천천히 회전하며 일시정지할 수 있습니다. 운영체제의 동작 줄이기 설정을 존중합니다.
3. 발견 모아보기: 원하는 사진 3개의 탐구를 마치면 필수 활동 완료, 남은 1개는 선택 탐구입니다. 관찰 근거와 실제 물체에서 단순화한 부분을 따로 적고 교사에게 함께 전달합니다.

밝고 따뜻한 파스텔 화면, 큰 터치 버튼, 사진별 진행 상태를 제공합니다. AI 후보와 기록은 사진별로 보관해 사진을 바꾸거나 화면을 다시 열어도 이어서 탐구합니다. AI는 연결된 상태에서 사용하며 직접 도형을 선택하는 탐구는 오프라인에서도 가능합니다.

학생 참여 토큰은 수업과 기기에 묶이며 자기 제출물만 조회·수정할 수 있습니다. 교사용 목록, 다른 모둠 사진, 수업 생성과 단계 변경은 서버가 차단합니다.

## 와이파이 끊김과 복구

- 사진과 입력 내용, 진행 단계, 전송 상태를 IndexedDB에 저장합니다.
- 사진마다 고정 ID와 수정 권한값을 사용합니다. 업로드 응답이 유실돼도 같은 사진을 중복 등록하지 않으며 최신 수정은 이어서 동기화합니다.
- 앱이 열린 상태에서 `online` 이벤트, 화면 복귀 또는 주기적 재시도 때 대기 중인 전송을 처리합니다.
- 페이지를 새로 열면 같은 브라우저의 IndexedDB에서 참여 정보와 기록을 복원합니다. 다른 수업으로 이동해도 기존 수업의 참여 정보와 기록은 기기에 남습니다.
- Service Worker는 학생 화면과 정적 자산만 캐시합니다. 첫 역할 선택 화면도 캐시하지만 교사 화면·인증·API·서버 사진은 캐시하지 않습니다. 최초 온라인 접속과 학생 화면의 오프라인 준비가 완료돼야 연결이 끊긴 상태의 새로고침/재열기가 가능합니다.
- 서버 마감이나 권한 오류는 계속 재전송하지 않고 기기에 기록을 보관하며 안내합니다. 교사가 수업을 재개한 뒤 다시 전송할 수 있습니다.
- 브라우저 데이터 삭제, 다른 브라우저/기기, 저장소 차단·용량 부족, 브라우저의 데이터 제거 시에는 로컬 기록 복원이 보장되지 않습니다. 오류를 표시하며 저장 성공으로 오인시키지 않습니다.
- 브라우저가 종료된 동안의 백그라운드 전송은 보장하지 않습니다. 연결 후 같은 학생 화면을 다시 열면 전송을 이어갑니다.

## 도형과 AI

다면체와 회전체 14종, 밑면 변 수와 크기 조절을 제공합니다. 각기둥·각뿔·각뿔대·기울어진 각기둥·정사면체·원기둥·원뿔·원뿔대의 전개·접기를 지원합니다. 구 등은 회전 생성으로 탐구합니다. 사진 모델은 수학적으로 단순화한 모델이며 정밀 실물 3D 스캔이 아닙니다.

Claude는 Sites 런타임 비밀값 `ANTHROPIC_API_KEY`로 연결합니다. 모델 기본값은 `claude-sonnet-4-6`, 필요하면 `CLAUDE_MODEL`로 학교가 허용한 모델을 지정합니다. 학생 참여 권한이 있고 마감되지 않은 수업에서만 호출할 수 있으며 수업당 최대 200회의 분석을 허용합니다. 키는 클라이언트·소스·로그에 노출하지 않습니다.

## 저장소와 검증

Vinext/React + Cloudflare Workers, D1 `DB`, R2 `BUCKET`을 사용합니다. 마이그레이션은 추가 방식으로 유지합니다. 기존 데이터와 수업은 보존하며 이전 버전 제출 기록은 교사만 볼 수 있습니다.

`node --test tests/geometry.test.mjs tests/classroom.test.mjs tests/vision.test.mjs tests/sync.test.mjs tests/offline-worker.test.mjs tests/teacher-session.test.mjs`

도형 수치와 전개, 교사/학생 권한 분리, 다른 모둠 격리, 중복 업로드 방지, 응답 유실 뒤 최신 수정 재전송, 연결 복구, 동시 편집 중 전송 응답, 마감 처리, AI 접근 권한과 오류 비노출, Service Worker 캐시 범위를 검증합니다. 실제 태블릿 브라우저·카메라와 기기별 와이파이 전환은 별도 현장 검증이 필요합니다.

사진 분석은 손잡이·작은 돌출부를 생략한 전체 외형을 우선합니다. 큰 구조는 보존하고, 후보별로 단순화한 부분·관찰 근거·확인할 점을 안내합니다. 지원하지 않는 결합 도형은 부분 모델의 한계를 명시합니다.
