## 디자인 고유성

- 상호작용 설계는 이 앱만의 것이에요. 사진 → 내 생각 → AI 후보 → 돌리고 펼치기 → 단순하게 본 부분 기록으로 이어져요.
- 겉모습은 어느 앱에나 붙일 수 있는 파스텔 템플릿이에요. 영문 머리말, 그라데이션 카드, 같은 아이콘 반복이 그래요.
- 주인공이어야 할 학생 사진이 48px 썸네일로 밀려나 있어요.

## 잘하고 있는 점

1. **도형 탐구실**
   - 돌려 보기·펼치고 접기·면 나누기·회전 생성 모드가 있어요.
   - 면을 누르면 힌트가 뜨고, 면·모서리·꼭짓점 개수를 보여 줘요.
2. **생각을 받쳐 주는 장치**
   - 내 생각을 먼저 쓰게 해요.
   - "AI의 제안은 정답이 아니에요"라고 알려 줘요.
   - 판단 보류를 허용하고, 문장 틀 예시를 줘요.
3. **기록을 잃지 않는다는 안심**
   - 기기 저장 → 전송 흐름이 있어요.
   - 오프라인 안내가 있어요.
   - AI 오류가 나도 쓰던 답안이 보존돼요.

## 우선순위 이슈

### [P1] 학생 탐구 화면: 화면 틀이 할 일을 묻어 버림

- **문제**
  - 띠 12개가 쌓여 있어요: 상단바 → 수업 리본 → 탭 → 진행 카운터 → 사진 띠 → 사진 헤더 → AI 배너 → 단계 → 제목 → 본문 → 버튼 → 하단 문구.
  - 1180×820 태블릿 첫 화면에 입력칸이 없어요.
  - 단계를 넘길 때마다 맨 위로 튀어요.
  - AI 버튼으로 1단계를 건너뛸 수 있어요.
- **고치는 방법:** `distill` → `layout`
  - 64px 안팎의 바 하나와 "사진 한 장 작업대"로 바꿔요.
  - AI는 2단계 안에만 둬요.
  - 다음 버튼은 카드 아래에 고정해요.

### [P1] 글자 대비와 크기가 교실에서 안 읽힘

- **문제**
  - 교사 게시판에서 기준(4.5:1) 미달 요소가 62개예요. 가장 낮은 것은 2.18:1이에요.
  - 학생 탐구 화면에서 미달 요소가 25개예요. 가장 낮은 것은 2.10:1이에요.
  - 11px 이하 글자 선언이 114곳이에요.
- **고치는 방법:** `typeset` + `colorize`
  - 글자색을 잉크·본문·보조 세 단계로 줄이고, 보조도 4.5:1 이상으로 맞춰요.
  - 학생 본문 16–18px, 칠판 본문 18px 이상으로 키워요.

### [P1] 교사 게시판이 투사용이 아님

- **문제**
  - 1080p에서 위 720px가 관리 UI예요.
  - 타이머가 22px 연두색이고, 새로고침하면 초기화돼요.
  - 상세 창의 닫기 X가 확대 버튼과 겹쳐요.
- **고치는 방법:** `adapt` + `bolder`
  - 별도 투사 모드를 만들어요.
  - 상단에 코드·단계·타이머, 본문에 분류 벽, 하단에 모둠별 진행을 둬요.

### [P1] 기본값이 수업을 잘못된 정보로 이끎

- **문제**
  - 손대지 않은 사진이 '판단 보류'·'관찰 중인 물체'·'6각기둥'으로 표시돼요.
  - 교사가 누르는 단계 버튼이 학생 화면에 영향이 없어요.
  - 마감 버튼이 확인 없이 붙어 있어요.
- **고치는 방법:** `clarify` + `harden`
  - '아직 생각 전'·'모델 고르기 전'을 별도 상태로 표시해요.
  - 단계 이름을 통일하고 학생 화면에도 반영해요.
  - 마감은 따로 떼어 확인을 받아요.

### [P2] 색 체계가 무너져 있음

- **문제**
  - 학생 주 버튼(#ffd2bb)의 배경 대비가 1.36:1이라 비활성 버튼과 구별되지 않아요.
  - 교사와 학생의 주 버튼 색이 서로 달라요.
  - 사진 타일 배경색에 의미가 없어요.
  - 오프라인 표시 색이 바뀌지 않아요.
- **고치는 방법:** `colorize` → `polish`
  - 행동 색을 하나로 통일해요.
  - 분류마다 색을 정해요.
  - 오프라인은 앰버로 표시해요.

## 사용자별 위험 신호

- **처음 쓰는 13세 학생**
  - 로고를 누르면 수업에서 이탈해요.
  - "필수 0/3 · 선택 0/1"의 뜻을 알 수 없어요.
  - 번호 체계가 세 겹이에요.
  - 오류가 화면 밖에 떠요.
  - 79개 목록에서 원하는 도형을 찾기 어려워요.
- **태블릿을 돌려 쓰는 모둠**
  - 단계를 넘길 때마다 맨 위로 튀어요.
  - 토스트가 사진 제목을 가려요.
  - 저장 상태 글자가 10–11px예요.
  - 390px 화면에서 탭이 2×2로 쌓여요.
- **접근성이 필요한 학생**
  - 보조 글자 대비가 2.1–2.9:1이에요.
  - 현재 단계를 색으로만 구분해요.
  - 분류 버튼에 `aria-pressed`가 없어요.
  - 창에 Esc 닫기와 포커스 가두기가 없어요.
  - 3D 회전이 드래그로만 돼요.
- **공개수업 교사**
  - 게시판 첫 화면이 관리 UI예요.
  - 어느 모둠이 막혔는지 안 보여요.
  - 참관인 앞에 운영 문구가 노출돼요.

## 작은 관찰

- Noto Sans KR을 이름만 지정하고 불러오지는 않아서, 맑은 고딕으로 대체될 수 있어요.
- 줄 간격 1.9–2.0이 31곳에 쓰였어요.

- 오류 탐정 화면은 AI 설명을 3D 모델보다 먼저 읽게 순서를 바꾸면 좋겠어요.
- 탐구를 마쳤을 때 마무리 연출이 없어요.
- (개발 서버에서만 확인) 서비스 워커가 개발 서버의 `/app/globals.css`를 캐시해서, 다시 열면 스타일이 빠져요. 운영 빌드는 확인하지 않았어요.
